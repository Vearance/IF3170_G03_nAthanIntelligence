# Tubes 1 AI

Repo ini menggunakan [uv](https://docs.astral.sh/uv/) untuk mengelola environment dan dependency Python.

## Perintah dasar

```bash
# Install/sinkronisasi dependency
uv sync

# Try visualizer
uv run vis
# or
uv run vis test/input/test-4.json

# Tambahkan dependency
uv add <nama-package>
```
